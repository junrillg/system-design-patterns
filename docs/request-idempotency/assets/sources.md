# Figure sources

`request-process.svg` is an editable educational diagram of the pinned Résumé Match API path. Its embedded Django, Python and PostgreSQL logos are reused unchanged from the [existing official assets and usage notes](../../transactional-outbox/assets/logos/sources.md). Logo proportions and colors are preserved; the marks identify technology and do not imply endorsement.

`request-cafe.png` was generated with the built-in image generation tool and inspected for consistent K/ORDER 42/1 LATTE identifiers and a single order ticket in each panel. The [saved prompt](request-cafe-prompt.txt) records the instructions. This is an analogy, not a screenshot of the application; K and 42 are short illustrative labels, while the API requires a UUID request key and uses UUID job IDs.
